Welcome to basis-ng

Streamline your Angular development workflow with basis-ng, a contemporary UI component library for Angular 19. Designed for efficiency, it provides reusable and highly customizable building blocks for your user interfaces.

Custom Design with Primitives

The primitives package provides unstyled components, making it ideal for applying your own design system and customizing the look and feel to suit your needs. For complete control over aesthetics, the primitives package offers foundational components without applied styles. It's the ideal base for building upon your existing design system or creating a new one from scratch, ensuring seamless visual integration. npm install @basis-ng/primitives

Rapid Implementation with Styles

Accelerate development with the styles package. It provides fully styled components with a cohesive and professional design, allowing you to build visually appealing interfaces with minimal setup effort. npm install @basis-ng/styles
